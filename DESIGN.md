## 0. Порядок работы — выполнять всегда

1. **Сначала Figma, потом код.** Любая визуальная правка (размер, цвет, состояние, новый блок или компонент) сначала вносится в кит / макет «к вёрстке», затем переносится в код.
2. **Не придумывать.** Чего нет в макете (меню, состояния, ошибки, пустые экраны, тексты) — спросить или предложить в Figma и согласовать, а не верстать «на глаз».
3. **Читать узел, а не картинку.** Размеры, отступы, стили текста — из `get_design_context` и `get_metadata`. Скриншот — только для сверки. Перед `get_design_context` — навык `figma:figma-design-to-code`, перед `use_figma` — `figma:figma-use`.
4. **Переиспользовать.** Сначала искать компонент в коде (таблица в §4). Новый повторяющийся элемент — компонент в ките → компонент в коде → витрина.
5. **Только токены** (§2). Hex, `px`-шрифты и произвольные цвета в классах запрещены, исключения — в §2.
6. **Интерактивный блок — по гайду** `modern-web-guidance` (правила — `AGENTS.md`, «Современная платформа»).
7. **Тексты — по-русски, через типограф** (§8).
8. **Проверить** (§10).

## 5. Состояния и анимации

Состояния кнопок и ссылок нарисованы в ките вариантами `State=…` (18.11.2026, предложение — согласовать с клиентом):

| Элемент | Hover | Focus | Pressed |
|---|---|---|---|
| Жёлтые кнопки (Primary, «Записаться») | `accent-yellow-hover`; у Primary стрелка сдвигается на 4 вправо | кольцо | `accent-yellow-pressed` |
| Тёмные кнопки («Подробнее», меню) | `accent-blue` | кольцо | `accent-blue-pressed` |
| Стрелка слайдера | заливка `bg-navy`, шеврон `text-inverse` | кольцо | — |
| Nav Link / телефон в шапке | текст `accent-blue` / `accent-yellow` | кольцо | — |

- **Кольцо фокуса** — одно на всё: 2 px `bg-white` + 2 px `accent-blue` снаружи, радиус = радиус элемента + отступ. В коде — `:focus-visible { box-shadow: 0 0 0 2px var(--bg-white), 0 0 0 4px var(--accent-blue) }` (видно и на белом, и на тёмно-синем). Только на `:focus-visible`, не на клик мышью.
- Hover — только под `@media (hover: hover)`, на тач-экранах его нет.
- Переход цвета — 150 мс `ease-out`; сдвиг стрелки — `transform`, при `prefers-reduced-motion: reduce` не двигается (цвет меняется).
- Disabled — прозрачность 18 % (стрелка в начале или конце ряда), в коде `disabled` + `aria-disabled`.

Фото и SVG — `public/images/`. **Фото:** оригинал заливки из Figma (`download_assets` → `rawImages`; картинки из `get_design_context` бывают уменьшены — карта пришла 1024 вместо 3111), уменьшить до 2× самого широкого слота среди всех ширин (декоративное размытое — 1,5×), WebP качество 85 один раз (Pillow); `next/image` — `quality={90}` (`images.qualities` в `next.config.ts`). **Слой из нескольких заливок или с эффектом** (карта: 3 слоя, постепенное размытие 2,66 — в CSS аналога нет, `blur()` размывает равномерно) — экспорт самого узла (`download_assets`, PNG 3×) с эффектом внутри, без CSS-эффектов; рамку в коде расширить на размер размытия. Сейчас: портрет 1000 (слот до 488), карта — экспорт узла `3051:1156` 2338 × 983 (слот до 1092), фото команды 2812 — улучшенное (18.11.2026, узел `3057:1158`), ровно 2× слота 1406. SVG — экспорт узла. Первый экран — `fetchPriority="high"`, остальные лениво. Тексты главной — `src/data/home.ts`, выделение `**…**` (`Rich`). Картинки из `public` — через `asset()` (`src/lib/asset.ts`), иначе на Pages не будет префикса `/rmk`.
